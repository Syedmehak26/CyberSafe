CyberSafe India — Cybersecurity Awareness Website

Files:
- index.html: complete responsive website; no build tools or server required.

How to open:
1. Extract the ZIP file.
2. Open the CyberSafe_India folder.
3. Double-click index.html to open it in a modern browser.

Features:
- English, Hindi and Telugu language selection.
- Cybersecurity awareness guides and incident help steps.
- Official reporting-resource links and search/filter.
- Educational threat-alert examples and learning cards.
- Interactive quiz with translated questions, options, explanations and results.
- Responsive layout for desktop and mobile.

Note: This is an independent educational awareness website, not a government portal. It does not submit complaints. Always verify reporting details on official services.
